PDO : PHP Data Object . 
la définition : 
PDO c'est une técnique ou extension  en PHP qui connecté à différentes bases de données de manière uniforme.
aussi permette de gérer la connexion de maniére  sécurisé . 
la structuration de PDO : 
$pdo = new PDO('mysql:host=localhost;dbname=ma_base', 'user', 'password');

try/catch : utilisé pour gérer les erreurs de connexion à la base de données.
